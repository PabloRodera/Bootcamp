# Bootcamp Backend Java - Repositorio de Laboratorios

Este repositorio contiene los laboratorios prácticos realizados durante mi participación en el **Bootcamp de Backend orientado a Java**. A lo largo del programa, se cubrieron conceptos clave de desarrollo backend, desde fundamentos de programación hasta la especialización en Java utilizando Spring Boot, con la implementación de metodologías ágiles y herramientas modernas como Docker, Kubernetes, y sistemas de gestión de colas como Kafka.

## Estructura del Bootcamp

El Bootcamp estuvo dividido en tres sprints, cada uno enfocado en diferentes aspectos del desarrollo backend. Los laboratorios fueron diseñados para ofrecer una base teórica sólida acompañada de ejercicios prácticos.

### Sprint 1: Fundamentos de Programación

Este sprint se centró en la adquisición de conceptos generales para el desarrollo, introduciendo herramientas esenciales y metodologías que son fundamentales en el ciclo de vida del desarrollo de software.

1. **Lab 1: Metodología Agile**
   - Introducción a la metodología Agile y su importancia en el desarrollo de software.
   - Implementación de Scrum para la gestión de proyectos.

2. **Lab 2: Repositorios Git**
   - Uso de Git y GitHub para el control de versiones y la colaboración en proyectos.
   - Conceptos como ramas, merge, y resolución de conflictos.

3. **Lab 3: Servidores, Kubernetes y MVC**
   - Introducción a los servidores web y contenedores con Kubernetes.
   - Explicación del patrón de arquitectura MVC (Model-View-Controller).

4. **Lab 4: Patrones de Diseño e Interfaces de Programación de Aplicaciones (APIs)**
   - Exploración de los patrones de diseño más comunes.
   - Implementación de APIs RESTful.

5. **Lab 5: Fundamentos de Integración y Entrega Continua (CI/CD)**
   - Uso de herramientas CI/CD para la integración y despliegue automatizado.
   - Configuración de pipelines de integración continua.

### Sprint 2: Desarrollo Backend

El segundo sprint profundizó en el uso de bases de datos, la creación de aplicaciones web con Docker y el modelado de microservicios.

1. **Lab 1: Aplicación Web con Docker**
   - Contenerización de aplicaciones web.
   - Uso de Docker para la creación y gestión de entornos de desarrollo.

2. **Lab 2: Bases de Datos (MongoDB y SQL)**
   - Introducción a bases de datos relacionales y no relacionales.
   - Modelado de bases de datos y consultas básicas en MongoDB y SQL.

3. **Lab 3: Sistemas de Caché**
   - Implementación de sistemas de caché para mejorar el rendimiento.
   - Exploración de herramientas como Redis y Memcached.

4. **Lab 4: Modelado de Microservicios**
   - Creación de microservicios desacoplados.
   - Diseño de sistemas escalables y distribuibles.

5. **Lab 5: Arquitectura Basada en Eventos y Sistemas de Gestión de Colas**
   - Introducción a la arquitectura basada en eventos.
   - Uso de sistemas de colas como RabbitMQ y Apache Kafka.

### Sprint 3: Especialización en Java con Spring Boot

Este sprint final se centró en la especialización con el lenguaje Java y el framework Spring Boot, cubriendo desde la configuración básica de un proyecto hasta temas avanzados como concurrencia, autenticación y sistemas de mensajería.

1. **Lab 1: Configuración de Arquetipo Spring Boot y Programación por Capas**
   - Creación de un proyecto básico en Spring Boot.
   - Organización de la aplicación en capas (controladores, servicios, repositorios).

2. **Lab 2: Definición de Endpoints**
   - Definición de endpoints RESTful con Spring Boot.
   - Uso de anotaciones como `@GetMapping`, `@PostMapping`, etc.

3. **Lab 3: Operaciones con Bases de Datos (Java + IntelliJ)**
   - Integración de bases de datos con Spring Data JPA.
   - Creación de entidades y repositorios.

4. **Lab 4: Concurrencia y Manejo de Hilos**
   - Uso de hilos para ejecutar tareas de forma concurrente en Java.
   - Implementación de `ExecutorService` y manejo de hilos en aplicaciones Spring.

5. **Lab 5: Autenticación y Autorización de Usuarios**
   - Implementación de seguridad en Spring Boot con Spring Security.
   - Creación de sistemas de autenticación y autorización de usuarios.

6. **Lab 6: Debugging, Testing y Calidad del Código**
   - Pruebas unitarias y de integración en Spring Boot.
   - Uso de herramientas de debugging y métricas de calidad del código.

7. **Lab 7: Gestión de Archivos y Recursos**
   - Manejo de archivos y recursos dentro de una aplicación Spring Boot.
   - Subida y descarga de archivos.

8. **Lab 8: Introducción a Kafka**
   - Integración de Apache Kafka para la mensajería asíncrona.
   - Configuración de productores y consumidores de mensajes.
